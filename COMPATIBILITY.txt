karui-oto — escritorios compatibles
====================================
Core (pickers MPD + fzf + kitty/foot) funciona en todos: solo necesita
mpd, mpc, fzf, bash, python3 y una terminal. Soportados con binds
automáticos: niri e hyprland (otros escritorios fueron recortados; el
historial git conserva sus traductores).

LEYENDA
  print   karui-oto binds <comp> genera el snippet
  sync    cada picker sincroniza shortcuts{} en segundo plano al abrir
          (backup + bloque marcado; --remove revierte)
  check   validacion nativa antes/después de aplicar
  float   ventana flotante por app-id (TERM_CLASS), siempre instalada
          junto a los binds, sin regla manual
  media   XF86AudioNext/Prev/Play -> karui-media (siempre instaladas,
          MPD primero: playerctl -p mpd, fallback mpc, nunca otro player)

  niri      print + sync + check (niri validate, auto-restore) + float + media
            config: ~/.config/niri/config.kdl (binds dentro de binds{},
            reglas flotantes top-level)
  hyprland  print + sync + check en vivo (hyprctl reload + configerrors,
            auto-restore) + float + media
            config: autodetect ~/.config/hypr/hyprland.lua (>= 0.55, Lua) o
            ~/.config/hypr/hyprland.conf (legacy). Binds + reglas en un
            bloque marcado; sin archivo = fallback guiado, nunca fatal.

NOTAS
  - Edita shortcuts{} y guarda: a la siguiente pulsación ya funciona.
    La pulsación que dispara el sync aún se comporta "a la vieja";
    borrados y reasignaciones quedan efectivos desde la segunda.
  - Logo: symbols en todos los terminales (header del picker); image solo
    kitty (window logo nativo: alpha/scale/posicion; tinte opcional con
    python3-pil y cache, sin el se usa la original). gif no soportado,
    1 imagen max. En foot las imagenes se ignoran con aviso.
  - Archivos gestionados por home-manager (symlink a /nix/store): --apply
    rehusa con instrucciones declarativas. Ver README NixOS.
  - Un marcador sin cerrar (edición a mano/crash) no se toca: aviso en vez
    de borrar hasta EOF.
